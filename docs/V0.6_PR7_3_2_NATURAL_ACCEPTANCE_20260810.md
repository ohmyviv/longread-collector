## Root-cause direction

### Publication format gap

`canonical-publication-v0.6-pr7.3.2` deliberately recognizes a standalone numeric absolute date/datetime only when the date begins its title-local line. That protected the system from restoring the old broad body-wide standalone-date scan.

The Jiemian template instead places the absolute date inside a title-local byline/metadata line:

```text
<author link> · <absolute date/time> 浏览 ... 来源：<publisher>
```

Therefore the date is true article-local evidence but does not match the current line-start cue.

The correct follow-up is not to weaken `publication_date_unknown_defer` and not to scan the whole body. A future narrow rule should recognize absolute date/time within a tight title-local metadata/byline line, anchored by structural markers such as author/byline separators plus `浏览` / `来源`.

### Self-source relationship gap

The same pages explicitly say `来源：界面新闻`, are hosted on Jiemian, identify Jiemian reporters, and expose no credible external original target. L4 should not classify such a self-attributed reporter page as `SECONDARY_REPUBLISH` merely because a hosting/source label or domain-normalization detail differs.

The precise implementation root should be reproduced in a fixture before changing source normalization. The semantic acceptance blocker is already established by the natural evidence.
