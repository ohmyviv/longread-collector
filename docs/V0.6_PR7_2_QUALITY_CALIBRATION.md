# v0.6 PR-7.2 — Template & Format Calibration

## Trigger

The first fully reviewed natural `collector-v0.6-pr7.1` pre-report run on
2026-08-09 passed the full-parallel engineering invariants but failed the
release quality gates:

- selected precision: **8/10 = 80.0%** (target >= 85%);
- strict actionable recall: **8/12 = 66.67%** (target >= 75%);
- serious false accepts: **2** (target 0).

PR-7.1's publication-date/freshness calibration materially worked: stale Yale
E360 material no longer leaked through. The remaining failures concentrated in
L5 Editorial Judge behavior.

## Residual failure modes

### 1. Moderate template contamination

Several complete Atlantic longreads had template risk around 0.38–0.46. The
PR-7.1 recovery path only reran scoring when the maximum original risk was at
least 0.55, so these articles never entered calibration even though their main
content was long, continuous, and substantive.

PR-7.2 therefore allows **conditional** recovery of moderate template risk
(0.25–0.55) when all of the following are true:

- the canonical asset is a written article on an article page;
- main-content prose is at least 4,500 compact characters;
- substance is already strong;
- promotion/event/transcript risks are not dominant;
- the main content shows multiple reporting/analysis/evidence signals.

The rule does **not** globally lower the 0.55 PR-7.1 threshold and does not
rescue short pages, event pages, transcripts, data cards, or promotion-heavy
content.

### 2. English newsletter / roundup structure

A 404 Media `The Abstract` special edition was ranked as the top longread even
though it bundled several unrelated studies.

PR-7.2 adds a combined format guard. A reject requires both:

- self-identification as a newsletter/roundup/briefing/special edition; and
- multi-story structure, such as multiple story headings or repeated
  `in this edition / in other news / another study` transitions.

A lone occurrence of the word `newsletter` is not sufficient.

### 3. Short low-depth news updates

The PR-2 canonical genre intentionally uses `reported_feature` as a broad
fallback for written articles. That fallback can admit ordinary event/news
updates into the longread portfolio.

PR-7.2 rejects only the narrow intersection of:

- canonical genre `reported_feature`;
- written article + article page;
- roughly 700–4,200 compact main-content characters;
- multiple update/event cues; and
- weak analysis, argument, evidence density, and original-reporting scores.

Explicit investigations, interviews, analysis, commentary, and other stronger
canonical genres are outside this guard.

## Non-goals

PR-7.2 intentionally does **not** change:

- Discovery or Acquisition Gate behavior;
- Jina / Direct HTML / Firecrawl acquisition;
- the 32-body-attempt budget;
- Firecrawl's daily fallback cap;
- publication-date precedence or the PR-7.1 freshness safety boundary;
- portfolio capacity, diversity weights, or source caps;
- legacy `collector-v0.5.6m` production authority;
- primary cache writes;
- the 07:35 editor connection;
- automatic promotion.

The portfolio algorithm is left unchanged first because the observed ALPR
selection regret can be explained by upstream false accepts and false rejects.
Portfolio tuning should occur only if regret remains after L5 correction.

## Validation

New regression coverage verifies:

1. substantive longreads can recover from moderate template contamination;
2. short low-depth pages are not rescued by that recovery;
3. self-identified multi-story newsletters are rejected;
4. a single newsletter mention does not cause a false reject;
5. short low-depth `reported_feature` fallbacks are rejected;
6. concise explicit investigations are exempt from the short-news guard;
7. the shadow version advances to `collector-v0.6-pr7.2` while control remains
   `collector-v0.5.6m`.

Existing PR-7.1 freshness tests and full-parallel zero-request/fail-open tests
remain authoritative and must continue to pass.

## Release semantics

PR-7.2 is a semantic quality change. After merge, release-acceptance counting
restarts from zero for the new frozen semantic version. CI, manual replays, and
manual collector runs are regression evidence only; only qualifying scheduled
natural shadow days can count toward the release gate.

The sidecar remains shadow-only and fail-open.
