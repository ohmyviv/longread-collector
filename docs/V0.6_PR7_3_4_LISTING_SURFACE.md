# v0.6 PR-7.3.4 — Newspaper issue/index page-surface recovery

## Trigger

The scheduled `pre_report` natural shadow on 2026-08-11 was:

```text
GitHub workflow run: 31429073894
collector run: COL-20260811-042738-BJT-pre_report
runtime: collector-v0.6-pr7.3.3
engineering invariants: PASS
semantic acceptance: FAIL
Natural Shadow acceptance: Day 0
```

The run exposed a new L4 page-surface blocker. The following URL reached the
v0.6 selected set at rank 1:

```text
http://mrdx.cn/h5/mrdx/content/20260810/PageArticleIndexLB.htm?pagetonum=01
```

with title:

```text
新华每日电讯 -微报纸-2026年08月10日
```

The acquired body was not one article. It was a whole newspaper issue/index with
multiple edition headings (`01版：要闻`, `02版：要闻`, ...), many links to
independent issue articles, and multiple article bodies concatenated into the
same acquisition payload.

PR-2's generic medium resolver classified any sufficiently long prose page as
`ARTICLE_PAGE + WRITTEN_ARTICLE`, so the issue container was passed to the frozen
L5 judge and ultimately selected as a standard longread.

## Scope

- legacy v0.5.6m control authority;
- PR-8/canary state.

## Fix

PR-7.3.4 adds a post-PR-7.3.3 L4 surface override. A page already classified as
`ARTICLE_PAGE + WRITTEN_ARTICLE` is changed to:

```text
PageSurface.LISTING
ContentMedium.UNKNOWN
```

only when all of the following are true:

1. issue identity is explicit in either the title (`微报纸` / `电子报` /
   `数字报` / `e-paper`) or an issue-index path (`PageArticleIndex*` /
   `IssueIndex`);
2. the first 30k acquired characters contain at least three numbered edition
   headings such as `#### 01版：要闻`;
3. the same bounded region contains at least five distinct same-host article
   links with newspaper-style `Article*` / `Articel*` paths;
4. the prior L4 result was specifically `ARTICLE_PAGE + WRITTEN_ARTICLE`.

The bounded region and conjunctive identity/structure requirements are intended
to avoid turning ordinary longreads, category pages, or distant reference links
into listing evidence.

The surface evidence version is:

```text
canonical-surface-v0.6-pr7.3.4
```

The canonical wrapper/runtime advance to:

```text
canonical-article-resolver-v0.6-pr7.3.4
collector-v0.6-pr7.3.4
```

while the underlying frozen components remain:

```text
canonical-medium-v0.6-pr2
canonical-publication-v0.6-pr7.3.3
canonical-source-v0.6-pr7.3.3
editorial-judge-v0.6-pr7.2
```

## Downstream behavior

No L5 code change is required. The existing frozen Editorial Judge already treats
`PageSurface.LISTING` as insufficient evidence for article-level editorial
judgment. Existing L6 policy then defers it rather than allowing standard
selection.

The regression therefore verifies the complete path:

```text
issue/index container
  -> L4 LISTING
  -> L5 INSUFFICIENT_EVIDENCE
  -> L6 DEFER
```

## Negative controls

Regression coverage also requires that the following remain ordinary articles:

- a real longread whose title merely mentions `电子报`;
- a long article containing many numbered section headings and external article
  links but without issue/index identity;
- an index-like URL without acquired multi-article structure.

## Acceptance semantics

Shadow acceptance.

After PR-7.3.4 merges, acceptance remains Day 0. The first subsequent scheduled
natural shadow on `collector-v0.6-pr7.3.4` becomes the next Day 1 candidate. PR-8
