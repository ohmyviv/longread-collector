# Collector v0.4 classification taxonomy

This file is the complete machine-facing taxonomy for `collector-v0.4.0`.
`docs/V0.4_SPEC.md` defines the release contract; this file lists both the
high-level categories and the granular values used by regression fixtures.

## Compatibility rule

During the shadow migration, `eligible_for_editor` is retained only as a
derived compatibility field:

```text
eligible_for_editor = candidate_disposition == formal_candidate
```

A/B/C/D verification levels remain technical extraction evidence and are not
part of this taxonomy.
