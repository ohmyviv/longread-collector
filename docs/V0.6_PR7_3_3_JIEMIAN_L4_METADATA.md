## Publication fix

PR-7.3.2 recognizes a standalone absolute date/datetime only when it begins its
own line in a tight title-local window. That guard is retained.

PR-7.3.3 adds one additional article-local cue:

```text
<byline cue> · <absolute local date/time> 浏览/阅读 ... 来源：<publisher>
```

Requirements are intentionally conjunctive:

1. the line must be inside the existing tight title-local sample;
2. it must contain an absolute YYYY local date/datetime;
3. it must contain a byline cue before the date (`·`, author link, 作者/记者);
4. it must contain a view/read marker;
5. it must contain an explicit source label.

The evidence source is:

```text
body_header_byline_datetime
```

with article-local provenance. Broad body-wide date scanning remains prohibited.

### Ready-gate timezone tightening

The first Ready review found that the initial matcher could lexically capture a
timezone-bearing datetime and then reduce it to its written calendar date. That
would bypass the existing Beijing-time rollover semantics.

The narrow PR-7.3.3 cue therefore **does not promote timezone-bearing timestamps**
such as:

```text
2026-08-10 17:30Z
2026-08-10 23:30-0700
```

Those remain the responsibility of the established timezone-aware publication
normalizer. PR-7.3.3 only calendar-normalizes the observed no-offset local forms
that triggered this patch (`2026年08月06日 05:07`, `2026/08/07 09:34`).

## Source relationship fix

The older PR-2-compatible source resolver can preserve
`secondary_republish + retain_current_display_url` when a human publisher label
is represented differently from the machine hosting representation.

PR-7.3.3 does not introduce a Jiemian allow-list. It recovers `ORIGINAL` only
when all of the following hold:

1. the prior result is exactly `SECONDARY_REPUBLISH` with
   `RETAIN_CURRENT_DISPLAY_URL`;
2. no stronger external-original, wire, translation, or primary-document action
   has already been established;
3. a tight title-local metadata line contains date + view/read + `来源/來源`;
4. that source publisher matches the page's own trailing title brand, such as
   `|界面新闻`;
5. the byline before the date contains a machine-checkable author/profile link
   on a sibling/parent subdomain of the current article site (for the natural
   sample, `www.jiemian.com` + `a.jiemian.com`).

The fifth condition was added during the Ready gate. Branding alone is not
sufficient evidence of self-publication: an aggregator whose title and copied
source label both say `新华社` must not become `ORIGINAL` merely because those two
strings agree.

When all conditions hold, the current page remains the canonical URL and the
relationship becomes `ORIGINAL` with `SourceAction.NONE`.

  same-host aggregator editor link exists — must remain secondary;
