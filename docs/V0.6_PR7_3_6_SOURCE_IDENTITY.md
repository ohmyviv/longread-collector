# PR-7.3.6 — L4 Source Identity and Agency Dateline Recovery

## Trigger

The 2026-08-11 scheduled `zh_midday` Natural Shadow exposed three source-resolution failures while the shared acquisition/control invariants remained useful for diagnosis. The failures are all confined to L4 Canonical Article source identity/relationship and are recoverable from evidence that was already acquired by the control run.

PR-7.3.6 therefore remains an L4-only follow-up. It does not alter Discovery, Acquisition, network requests, L5 Editorial Judge, L6 selection policy, or legacy `collector-v0.5.6m` authority.

## Natural evidence

### 1. Registered source lost at the compatibility boundary

Natural New Beijing News item:

- URL: `https://www.bjnews.com.cn/detail/1785892533169279.html`
- title: `国家科技伦理委员会委员翟晓梅：女童基因编辑悲剧中伦理为何失守`
- discovery source: `bjnews-depth`
- source name already present in discovery metadata: `新京报·深度`

The PR-2-compatible hosting resolver checks nested legacy metadata shapes but not the top-level `source_name` carried by the v0.6 DiscoveryRecord. With no recognized nested source, it can fall back to a short title that looks institution-like. Because this title contains `国家` and `委员会`, the complete article title became the hosting/canonical source.

PR-7.3.6 recovers top-level registered `source_name` only when:

1. a non-empty `source_id` is also present; and
2. the previously resolved hosting source is exactly the article title/title hint after normalization.

It is deliberately not a general rule that registered source metadata always overrides article-local source evidence.

### 2. Same-line source labels consumed editorial metadata

Natural North Country Network item:

- URL: `http://news.lnd.com.cn/system/2026/08/11/030570160.shtml`
- acquired header: `理论│2026-08-11 08:01 来源：辽宁日报 作者： 编辑：栾溪`

The earlier source label matcher stops mainly at pipes/newlines, so the publisher could become `辽宁日报 作者： 编辑：栾溪`.

PR-7.3.6 adds a title-local boundary recovery that stops an explicit source label before unambiguous metadata labels:

- `作者`
- `编辑/編輯`
- `责编/責編`
- `记者/記者`
- `校对/校對`
- `审核/審核`

The correction is applied only when the prior explicit-source evidence is demonstrably contaminated by one of those labels. A normal publisher such as `辽宁日报社评论部` is not truncated merely because it contains ordinary Chinese words.

### 3. Strict Xinhua lead dateline was not represented in L4 agency semantics

Natural New Beijing News item:

- URL: `https://www.bjnews.com.cn/detail/1786024638129401.html`
- title: `何为对外贸易国家安全调查？为何说调查产品与国家安全利益密切相关？专家解读`
- registered host: `新京报·深度`
- first paragraph begins: `据新华社北京8月6日电 ...`

The existing PR-7.3 source resolver has strong Reuters/AP wire evidence but no equivalent Xinhua dateline cue. If only the title-fallback defect were fixed, this item could incorrectly become a New Beijing News original.

PR-7.3.6 recognizes only a strict title-local lead pattern of the form:

`[据]新华社 + place + M月D日 + 电`

This resolves:

- `hosting_source = 新京报·深度`
- `canonical_source = 新华社`
- `original_publisher = 新华社`
- `source_relationship = wire_republish`
- `source_action = find_original_article`
- current display URL retained until an original URL is actually known

No request is made to search for the original article during L4 canonicalization.

## Precedence and safety

PR-7.3.6 wraps `source_resolution_v0733` and preserves stronger existing evidence:

- explicit original-source URL replacement from PR-7.3/7.3.2;
- translated republication;
- Reuters/AP wire evidence;
- Jiemian same-site self-source recovery from PR-7.3.3;
- primary-document actions already established by prior layers.

The Xinhua cue does not override an existing translated/wire relationship or an already resolved `REPLACE_WITH_ORIGINAL` action. It also does not convert direct Xinhua publisher pages into republications: registered `新华社`/`新华网` identity and direct `news.cn`/`xinhuanet.com` hosts remain on the prior original-publication semantics.

Registered hosting-source recovery only replaces canonical/original identity when the prior result is `ORIGINAL + NONE` and that identity is the same title-derived hosting fallback. Otherwise it repairs only `hosting_source`.

## Negative controls

Regression coverage includes:

1. a direct Xinhua page with the same `新华社...日电` dateline remains original;
2. ordinary mid-body mentions of `新华社` do not trigger agency republication;
3. an institution-like title without registered source metadata keeps prior behavior;
4. a normal publisher label such as `辽宁日报社评论部` is not truncated;
5. existing Jiemian self-source cases remain original;
6. existing PR-7.3.2 original-link semantics remain unchanged;
7. PR-7.3.4 newspaper listing surface remains frozen;
8. PR-7.3.5 snapshot persistence remains frozen.
